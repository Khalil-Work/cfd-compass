## 🎨 Visualization, post-processing & I/O

Inspect, process, exchange and communicate simulation data.

| Project / use case | What it offers | Selection notes |
| --- | --- | --- |
| **[ADIOS2](https://github.com/ornladios/ADIOS2)**<br>HPC output and streaming pipelines | Scalable scientific input/output framework transporting self-describing variables through files, networks and memory. Useful for large CFD output pipelines, streaming analysis and reducing coupling between simulation and data consumers.<br>[Docs](https://adios2.readthedocs.io/en/latest/) · `Apache-2.0` | Established · Requires integration into the application or an existing compatible I/O path. |
| **[CGNS](https://github.com/CGNS/CGNS)**<br>Standardized CFD data exchange | Defines and implements a standard for storing CFD meshes, flow solutions and related metadata. Useful when interoperability and consistent exchange between preprocessing, simulation and postprocessing tools matter.<br>[Docs](https://cgns.org/) · `NOASSERTION` | Established · A data model and library, not a solver; interoperable use still depends on supported CGNS conventions. |
| **[netCDF4-Python](https://github.com/Unidata/netcdf4-python)**<br>Geophysical CFD array I/O | Python and NumPy interface to the netCDF library. Useful for reading, writing and inspecting array-based simulation datasets, especially geophysical and atmospheric fluid workflows using netCDF conventions.<br>[Docs](https://unidata.github.io/netcdf4-python/) · `MIT` | Established · Respect netCDF thread-safety limitations and preserve units, coordinates and metadata conventions. |
| **[ParaView](https://github.com/Kitware/ParaView)**<br>General CFD postprocessing | Scientific visualization application built on VTK, supporting large-data analysis and programmable pipelines. Widely useful for CFD field inspection, slices, streamlines, time histories and reproducible postprocessing workflows.<br>[Docs](https://docs.paraview.org/en/latest/) · `BSD-3-Clause` | Established · Official GitHub mirror; upstream development and issue reporting take place on Kitware GitLab. |
| **[PyVista](https://github.com/pyvista/pyvista)**<br>Python mesh and field analysis | NumPy-friendly Python interface to VTK datasets, filters and plotting. Supports scripted extraction, slicing and interactive display of CFD meshes and fields in notebooks, applications or automated reporting.<br>[Docs](https://docs.pyvista.org/) · `MIT` | Established · Headless rendering and remote notebook use may require additional graphics configuration. |
| **[trame](https://github.com/Kitware/trame)**<br>Browser-based CFD viewers | Python framework for interactive scientific web applications, integrating VTK and ParaView rendering. Useful for turning CFD analysis pipelines into browser-accessible viewers with local or remote visualization.<br>[Docs](https://kitware.github.io/trame/) · `NOASSERTION` | Established · Application deployment, authentication and resource limits need separate design for public-facing services. |
| **[vedo](https://github.com/marcomusy/vedo)**<br>Compact interactive visualization scripts | Python scientific visualization built on VTK and NumPy, with mesh manipulation and analysis helpers. Useful for compact exploratory scripts, interactive inspection and presentation of surfaces or volumetric flow data.<br>[Docs](https://vedo.embl.es/) · `MIT` | Established · Check supported readers and field association conventions against the output format of your solver. |
| **[VisIt](https://github.com/visit-dav/visit)**<br>Large mesh-based simulation analysis | Scientific visualization and analysis application for mesh-based simulation data. Useful for exploring large CFD datasets, applying derived quantities and building repeatable analysis routines across supported simulation formats.<br>[Docs](https://visit-sphinx-github-user-manual.readthedocs.io/) · `BSD-3-Clause` | Established · Solver output must match a supported reader or be converted to an appropriate exchange format. |
| **[VTK](https://github.com/Kitware/VTK)**<br>Custom scientific visualization software | Visualization and data-processing toolkit for building scientific applications. Provides meshes, filters, rendering and file readers that underpin custom CFD postprocessing tools and many established visualization applications.<br>[Docs](https://docs.vtk.org/en/latest/) · `NOASSERTION` | Established · A development toolkit rather than a complete end-user CFD application; GitHub is an official mirror. |
| **[yt](https://github.com/yt-project/yt)**<br>AMR and astrophysical-fluid data analysis | Python analysis and visualization for volumetric simulation datasets, including adaptive meshes. Useful for derived fields, spatial selections, profiles and volume rendering in computational astrophysics and related fluid simulations.<br>[Docs](https://yt-project.org/doc/) · `NOASSERTION` | Established · Strongest fit is supported volumetric simulation formats; confirm a frontend exists for your solver. |
