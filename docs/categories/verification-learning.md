## 🔬 Verification, benchmarks & learning

Teaching material, reference cases, datasets and numerical checks.

| Project / use case | What it offers | Selection notes |
| --- | --- | --- |
| **[CFD Python](https://github.com/barbagroup/CFDPython)**<br>First-principles CFD learning | A notebook sequence teaching CFD through incremental PDE implementations, culminating in Navier–Stokes exercises. Useful for understanding discretization, numerical diffusion and convergence before adopting larger solver frameworks.<br>[Docs](https://github.com/barbagroup/CFDPython#readme) · `NOASSERTION` | Established · Educational discretizations and small examples are not production CFD solvers. |
| **[CFDBench](https://github.com/luo-yining/CFDBench)**<br>Parameterized CFD surrogate comparisons | Fluid-dynamics surrogate benchmark with cavity, tube, dam and cylinder cases across boundary conditions, geometries and physical properties. Includes datasets and baseline implementations for studying inference-time generalization.<br>[Docs](https://github.com/luo-yining/CFDBench#readme) · `NOASSERTION` | Research · Original data generation uses commercial ICEM/Fluent; using released data has separate download and storage requirements. |
| **[FEniCSx Tutorial](https://github.com/jorgensd/dolfinx-tutorial)**<br>Finite-element flow implementation learning | Executable finite-element tutorial covering DOLFINx fundamentals and Navier–Stokes examples. Useful for deriving weak forms, applying boundary conditions and exploring transparent flow implementations with associated explanations and parallel execution.<br>[Docs](https://jsdokken.com/dolfinx-tutorial/) · `NOASSERTION` | Established · Follow the tutorial's supported DOLFINx version; examples are not a universal production flow solver. |
| **[Giverny / JHTDB access](https://github.com/sciserver/giverny)**<br>Reference DNS turbulence queries | Python and MATLAB access tools for querying the Johns Hopkins Turbulence Database. Enables sampled DNS fields and cutouts for turbulence analysis, numerical comparisons and data-driven research without downloading entire simulations.<br>[Docs](https://turbulence.idies.jhu.edu/database) · `Apache-2.0` | Established · Access tokens, query-size limits and available variables depend on the service and chosen dataset. |
| **[MASA](https://github.com/manufactured-solutions/MASA)**<br>Method-of-manufactured-solutions verification | Library of manufactured analytical solutions and source terms for PDE software verification. Includes Euler, Navier–Stokes and turbulence-model formulations useful for checking implementation errors and observed convergence orders.<br>[Docs](https://manufactured-solutions.github.io/MASA/) · `NOASSERTION` | Established · Manufactured solutions verify equation implementation; they do not validate physical modelling against experiments. |
| **[NekExamples](https://github.com/Nek5000/NekExamples)**<br>Nek5000 example and verification cases | Official Nek5000 examples with case descriptions and required simulation files. Includes canonical and turbulent-flow setups useful for learning spectral-element workflows, inspecting boundary conditions and checking an installation.<br>[Docs](https://github.com/Nek5000/NekExamples#readme) · `NOASSERTION` | Established · Examples require Nek5000 and case-specific preparation; confirm mesh resolution and expected reference quantities. |
| **[PDEBench](https://github.com/pdebench/PDEBench)**<br>Standardized fluid-surrogate evaluation | Scientific machine-learning benchmark combining PDE datasets, data-generation code and baseline models. Fluid cases and varied initial, boundary and physical parameters support repeatable comparisons of learned flow prediction methods.<br>[Docs](https://github.com/pdebench/PDEBench#readme) · `NOASSERTION` | Research · Datasets are hosted separately and can be large; check documented environment and data-path requirements. |
| **[preCICE Tutorials](https://github.com/precice/tutorials)**<br>Coupled CFD learning cases | Worked coupled-simulation cases using preCICE with real solvers, including fluid–structure and thermal applications. Useful for understanding participant configuration, adapter interfaces and reproducible multiphysics setup rather than isolated equations.<br>[Docs](https://precice.org/tutorials.html) · `LGPL-3.0` | Established · Most tutorials need multiple solver installations and adapters with compatible versions. |
| **[Riemann Problems and Jupyter Solutions](https://github.com/clawpack/riemann_book)**<br>Hyperbolic-flow numerical methods | Interactive notebook book covering Riemann problems for hyperbolic equations, including acoustics, shallow water and Euler flow. Useful for understanding wave structure and comparing exact or approximate flux solvers.<br>[Docs](https://www.clawpack.org/riemann_book/html/Index.html) · `BSD-3-Clause` | Established · Text and executable code have separate license files; consult both when reusing material. |
| **[Riemann-Solvers](https://github.com/cangyu/Riemann-Solvers)**<br>Hands-on flux-solver comparison | Compact implementations accompanying classical Riemann-solver methods for advection, Burgers and Euler equations. Useful for comparing schemes and developing intuition about shocks, rarefactions and numerical fluxes.<br>[Docs](https://github.com/cangyu/Riemann-Solvers#readme) · `NOASSERTION` | Research · No repository-level license was apparent in the inspected listing; inspect permissions before copying code. |
| **[SU2 TestCases](https://github.com/su2code/TestCases)**<br>SU2 regression and setup examples | Official collection of SU2 test inputs spanning flow, adjoints, conjugate heat transfer and other capabilities. Useful for reproducing regression cases and finding solver-specific examples matched to SU2 development.<br>[Docs](https://github.com/su2code/TestCases#readme) · `LGPL-2.1` | Established · Match the case branch or revision to the SU2 solver version; a regression pass is not physical validation. |
