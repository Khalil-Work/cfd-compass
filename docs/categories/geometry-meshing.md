## 📐 Geometry, CAD & mesh generation

Geometry preparation, mesh generation, adaptation and quality tools.

| Project / use case | What it offers | Selection notes |
| --- | --- | --- |
| **[CadQuery](https://github.com/CadQuery/cadquery)**<br>Scripted geometry sweeps | Python-based parametric CAD scripting built on Open CASCADE. Parameterized channels, nozzles and mechanical components can be generated consistently for geometry sweeps, automated studies and downstream mesh preparation.<br>[Docs](https://cadquery.readthedocs.io/) · `NOASSERTION` | Established · Provides geometry construction rather than a CFD mesher or solver. |
| **[CGAL](https://github.com/CGAL/cgal)**<br>Geometry algorithms and mesh infrastructure | Computational geometry algorithms for triangulation, surface processing and mesh generation. Supplies robust geometric building blocks for custom CFD preprocessing tools rather than a single ready-made flow-analysis workflow.<br>[Docs](https://doc.cgal.org/latest/Manual/packages.html) · `NOASSERTION` | Established · License terms differ by CGAL package; check the specific component before integration. |
| **[FreeCAD](https://github.com/FreeCAD/FreeCAD)**<br>Parametric engineering geometry | Parametric solid modelling for engineering geometry, with editable design history and interoperable CAD workflows. Useful for preparing and revising fluid-domain boundaries before meshing rather than solving flow.<br>[Docs](https://www.freecad.org/) · `LGPL-2.1` | Established · A CAD model is not automatically a watertight or appropriately resolved CFD domain. |
| **[IDWarp](https://github.com/mdolab/idwarp)**<br>Volume-mesh deformation | Deforms volume mesh nodes in response to surface perturbations using an inverse-distance approach. Useful for reusing a baseline CFD mesh during aerodynamic shape optimization and sensitivity calculations.<br>[Docs](https://mdolab-idwarp.readthedocs-hosted.com/en/latest/) · `NOASSERTION` | Established · Large surface changes can still produce poor-quality or invalid cells; monitor mesh quality. |
| **[meshio](https://github.com/nschloe/meshio)**<br>Mesh-format conversion | Reads and writes many mesh formats through Python and a command-line interface. Helps move geometry, cells and associated fields between meshing tools, numerical solvers and visualization software.<br>[Docs](https://github.com/nschloe/meshio#readme) · `MIT` | Established · Not every format preserves every field, boundary convention or high-order element representation. |
| **[Netgen](https://github.com/NGSolve/netgen)**<br>Scriptable tetrahedral meshes | Automatic tetrahedral mesh generation from constructive geometry, STL surfaces and CAD geometry. Python scripting, refinement and optimization make it useful for reproducible finite-element flow preprocessing.<br>[Docs](https://github.com/NGSolve/netgen#readme) · `LGPL-2.1` | Established · Mesh topology, boundary tagging and wall-resolution requirements still need solver-specific checking. |
| **[pygalmesh](https://github.com/meshpro/pygalmesh)**<br>Implicit-domain tetrahedral meshing | Python interface to CGAL's mesh-generation capabilities, including primitive and implicit domains. Useful for constructing tetrahedral meshes from mathematical geometries and exporting them for numerical PDE experiments.<br>[Docs](https://github.com/meshpro/pygalmesh#readme) · `GPL-3.0` | Established · Sharp intersections and detailed meshing controls need care; this is not a CAD repair application. |
| **[pyGeo](https://github.com/mdolab/pygeo)**<br>Shape parameterization for CFD optimization | Geometry parameterization and geometric constraints for multidisciplinary optimization. Free-form deformation, CAD interfaces and design-variable handling connect aerodynamic shape changes to repeatable CFD and coupled engineering studies.<br>[Docs](https://mdolab-pygeo.readthedocs-hosted.com/en/latest/) · `Apache-2.0` | Established · Individual CAD interfaces introduce their own installation and licensing requirements. |
| **[pygmsh](https://github.com/nschloe/pygmsh)**<br>Python-driven Gmsh geometry | Python geometry helpers around Gmsh reduce repetitive low-level entity bookkeeping. Useful for creating parameterized two- and three-dimensional domains and exporting meshes into automated numerical experiments.<br>[Docs](https://github.com/nschloe/pygmsh#readme) · `GPL-3.0` | Established · Requires Gmsh; native Gmsh features and version compatibility should be checked for advanced workflows. |
| **[pyHyp](https://github.com/mdolab/pyhyp)**<br>Structured aerodynamic volume meshes | Extrudes structured surface meshes into volume meshes using hyperbolic marching. Designed for the preprocessing stage of aerodynamic optimization workflows where body-fitted structured grids and controlled extrusion are useful.<br>[Docs](https://mdolab-pyhyp.readthedocs-hosted.com/en/latest/) · `NOASSERTION` | Established · Needs a suitable structured surface mesh; it is not an arbitrary-geometry unstructured mesher. |
| **[SALOME SMESH](https://github.com/SalomePlatform/smesh)**<br>Interactive mesh preparation and quality checks | SALOME's mesh module creates, edits, imports and exports computational meshes, with grouping, quality controls and geometry integration. Supports preprocessing pipelines needing interactive inspection alongside structured automation.<br>[Docs](https://docs.salome-platform.org/latest/gui/SMESH/index.html) · `LGPL-2.1` | Established · Building the module requires additional SALOME components; the repository is not a standalone application installer. |
| **[trimesh](https://github.com/mikedh/trimesh)**<br>STL surface inspection | Python tools for loading, inspecting and manipulating triangular surfaces. Helpful for checking imported STL geometry, connectivity and surface properties before committing to expensive volume meshing or flow calculations.<br>[Docs](https://trimesh.org/) · `MIT` | Established · Surface processing does not establish CAD fidelity or the adequacy of a CFD boundary-layer mesh. |
