# Changelog

## 1.0.0 - 2026-10-25

Initial public reference edition: primary-source catalogue covering14 CFD topic areas; canonical repository links, use cases and selection notes; a dated GitHub metadata snapshot; official external resources; searchable static directory; CSV/JSON exports; original vector identity; and a linked, bookmarked PDF with an alphabetical index.

Includes structural/duplicate checks, documented contribution criteria, issue forms, citation metadata, a read-only PR validation workflow, manual/scheduled audit reports and GitHub Pages deployment. This release does not claim independent execution or numerical validation of all listed projects.
